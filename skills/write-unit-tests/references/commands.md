# Commands

| Name         | Command                         | Purpose            |
| ------------ | ------------------------------- | ------------------ |
| `git-root`   | `git rev-parse --show-toplevel` | Project directory  |
| `list-files` | `git ls-files`                  | List tracked files |
| `git-mv`     | `git mv <from> <to>`            | Relocate a test    |
