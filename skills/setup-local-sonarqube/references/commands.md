# Commands

`<root>` is filled per run.

| Name            | Command                                                                                                      | Purpose                                                                                                                                                                                                                                                                                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `repo-root`     | `git rev-parse --show-toplevel`                                                                              | Repository root (preloaded in Context)                                                                                                                                                                                                                                                                                                                       |
| `detect`        | `node ${CLAUDE_SKILL_DIR}/scripts/sonar-setup.mjs detect --root <root> [--stack <maven\|gradle>]`            | JSON `{key, name, stack, scanner, jdk, wrapper, exclusions, excluded, dropped, stop?, ask?}`: read-only stack detection per `flow.md` `## Stack`; `--stack` resolves an `ask`; one stderr line and exit 1 on error                                                                                                                                           |
| `compose`       | `node ${CLAUDE_SKILL_DIR}/scripts/sonar-setup.mjs compose --root <root> [--stack <maven\|gradle>] [--force]` | Detects the stack, resolves the tags (at most once per day), writes `compose.sonar.yaml` and `.vscode/tasks.json`; JSON `{path, stack, services, server, scanner, tasks, taskLabels, dropped, stop?, ask?, tasksStop?}`; an `ask` or `stop` = `compose.sonar.yaml exists` writes nothing; `image tag unresolved` error → stop                                |
| `docker-info`   | `docker info`                                                                                                | Docker availability                                                                                                                                                                                                                                                                                                                                          |
| `compose-check` | `docker compose -f compose.sonar.yaml config -q`                                                             | Run in `<root>`; exit 0 means the file is valid Compose                                                                                                                                                                                                                                                                                                      |
| `server-state`  | `docker compose -f compose.sonar.yaml ps -q sonarqube`                                                       | Run in `<root>`; a container id means the server is running, empty output means it is not                                                                                                                                                                                                                                                                    |
| `server-up`     | `docker compose -f compose.sonar.yaml up -d --wait --wait-timeout 300 sonarqube`                             | Run in `<root>`; starts the server and waits for its healthcheck; non-zero exit → `Env: skipped (server did not start)`                                                                                                                                                                                                                                      |
| `configure`     | `node ${CLAUDE_SKILL_DIR}/scripts/sonar-setup.mjs configure --root <root>`                                   | Sets the admin password, reads the port from `docker compose port`, creates the project, rotates the analysis token, writes `.env.sonar` (mode 600) and the `.gitignore` entry; JSON `{env, url, password, project, token, tokenType, gitignore, stop?}` with no secret value; `stop` = `server not UP (<status>)` or `admin password unknown`; error → stop |
| `server-stop`   | `docker compose -f compose.sonar.yaml stop sonarqube`                                                        | Run in `<root>`; stops the server and keeps its volumes                                                                                                                                                                                                                                                                                                      |
