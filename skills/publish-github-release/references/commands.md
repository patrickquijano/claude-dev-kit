# Commands

| Name                    | Command                                                                                                                                                      | Purpose                                             | MCP tool                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------- | ------------------------------------------ |
| `root`                  | `git rev-parse --show-toplevel`                                                                                                                              | Repository root (preloaded in Context)              | —                                          |
| `origin-url`            | `git remote get-url origin`                                                                                                                                  | Origin URL (preloaded in Context)                   | —                                          |
| `gh-version`            | `gh --version`                                                                                                                                               | gh installed                                        | —                                          |
| `gh-auth`               | `gh auth status`                                                                                                                                             | gh authenticated                                    | —                                          |
| `repo-view`             | `gh repo view --json nameWithOwner,url,viewerPermission`                                                                                                     | Repo and permission                                 | —                                          |
| `release-list`          | `gh release list --limit 1000 --json tagName,name,isDraft,isPrerelease,createdAt`                                                                            | Finds draft releases                                | `mcp__plugin_github_github__list_releases` |
| `release-view`          | `gh release view <tag> --json url,tagName,name,body,isDraft,isPrerelease,targetCommitish`                                                                    | One release's state and notes                       | —                                          |
| `remote-tag`            | `git ls-remote origin "refs/tags/<tag>" "refs/tags/<tag>^{}"`                                                                                                | Tag on origin (empty = absent)                      | —                                          |
| `scratch`               | `mktemp -d`                                                                                                                                                  | Scratch directory                                   | —                                          |
| `notes`                 | `node ${CLAUDE_SKILL_DIR}/scripts/changelog-notes.mjs notes --version <version or latest> --notes-out <scratch>/notes.md`                                    | Changelog section as release notes                  | —                                          |
| `create-draft`          | `gh release create <tag> --draft --verify-tag --title <tag> --notes-file <scratch>/notes.md`                                                                 | New draft release; aborts when the tag is absent    | —                                          |
| `discussion-categories` | `gh api graphql -f query='query($o:String!,$n:String!){repository(owner:$o,name:$n){discussionCategories(first:25){nodes{name}}}}' -f o=<owner> -f n=<name>` | Discussion categories (empty = discussions off)     | —                                          |
| `action-file`           | `git ls-files action.yml action.yaml`                                                                                                                        | Action metadata at the root (empty = not an Action) | —                                          |
| `update-notes`          | `gh release edit <tag> --notes-file <scratch>/notes.md`                                                                                                      | Replace a draft's notes, stays a draft              | —                                          |
| `publish-latest`        | `gh release edit <tag> --draft=false --latest [--notes-file <scratch>/notes.md] [--discussion-category <category>]`                                          | Publish a draft as the latest release               | —                                          |
| `publish-prerelease`    | `gh release edit <tag> --draft=false --prerelease [--notes-file <scratch>/notes.md] [--discussion-category <category>]`                                      | Publish a draft as a pre-release                    | —                                          |
| `verify-release`        | `gh release view <tag> --json url,tagName,isDraft,isPrerelease,targetCommitish`                                                                              | Verify the published release                        | —                                          |
