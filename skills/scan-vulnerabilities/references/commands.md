# Commands

| Name                   | Command                                                                                                                                                                                                                                                                                                                            | Purpose                                                                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `repo-root`            | `git rev-parse --show-toplevel`                                                                                                                                                                                                                                                                                                    | Repository root (preloaded in Context)                                                                                            |
| `docker-info`          | `docker info`                                                                                                                                                                                                                                                                                                                      | Docker availability                                                                                                               |
| `status-porcelain`     | `git status --porcelain`                                                                                                                                                                                                                                                                                                           | Uncommitted and unmerged paths                                                                                                    |
| `check-ignore-reports` | `git check-ignore -q .vulnerability-reports/`                                                                                                                                                                                                                                                                                      | Reports dir already ignored                                                                                                       |
| `exclude-reports`      | `echo '.vulnerability-reports/' >> .git/info/exclude`                                                                                                                                                                                                                                                                              | Ignore the reports dir locally when `check-ignore-reports` fails (`flow.md` `## Pre-flight`)                                      |
| `tracked-files`        | `git ls-files`                                                                                                                                                                                                                                                                                                                     | File is tracked                                                                                                                   |
| `default-branch`       | `git symbolic-ref --short refs/remotes/origin/HEAD`                                                                                                                                                                                                                                                                                | Default branch with `origin/`                                                                                                     |
| `checkpoint`           | `git stash create`                                                                                                                                                                                                                                                                                                                 | Snapshot of the tracked changes without a stash entry; empty output → `git rev-parse HEAD`                                        |
| `checkpoint-save`      | `CP=$(git stash create); [ -n "$CP" ] \|\| CP=$(git rev-parse HEAD); CK="<run dir>/iteration-<n>/checkpoints/R<i>.<k>"; mkdir -p "$(dirname "$CK")"; git status --porcelain=v1 > "$CK.status"; git ls-files --others --exclude-standard > "$CK.untracked"; git rev-parse --abbrev-ref HEAD > "$CK.branch"; echo "$CP" > "$CK.sha"` | Record a checkpoint before an attempt, in one call (`remediation.md` `## Checkpoint`)                                             |
| `rollback-attempt`     | the script in `remediation.md` `## Rollback`                                                                                                                                                                                                                                                                                       | Revert only the failed attempt from its saved checkpoint, in one call                                                             |
| `branch-current`       | `git rev-parse --abbrev-ref HEAD`                                                                                                                                                                                                                                                                                                  | Current branch; compare with the checkpoint `.branch` file (`remediation.md` `## Branch`)                                         |
| `head-sha`             | `git rev-parse HEAD`                                                                                                                                                                                                                                                                                                               | HEAD for `manifest.json` at pre-flight                                                                                            |
| `command-check`        | `command -v <tool>`                                                                                                                                                                                                                                                                                                                | Tool installed before a stack-default validation command                                                                          |
| `validation-run`       | the detected command (`remediation.md` `## Validation commands`)                                                                                                                                                                                                                                                                   | Build, type check, or test command, run by its detected text                                                                      |
| `rollback-verify`      | `git diff --quiet <checkpoint sha> -- <changed files>`                                                                                                                                                                                                                                                                             | Confirm the rollback restored the files (`remediation.md` `## Rollback`)                                                          |
| `rollback-file`        | `git restore --source=<checkpoint sha> --worktree -- <file>`                                                                                                                                                                                                                                                                       | Revert one file of a failed attempt (`remediation.md` `## Rollback`)                                                              |
| `release-list`         | `curl -fsS --max-time 20 "https://api.github.com/repos/<release source>/releases?per_page=100&page=<n>"`                                                                                                                                                                                                                           | One page of a scanner's releases (`scanners.md` `## Image resolution`, step 1)                                                    |
| `scanner-pull`         | `docker pull <image repo>:<tag>@<digest>`                                                                                                                                                                                                                                                                                          | Pull a resolved scanner image that `docker image inspect` does not find                                                           |
| `image-digest`         | `docker buildx imagetools inspect <image repo>:<tag> --format '{{json .Manifest}}'`                                                                                                                                                                                                                                                | Read its `digest` field: multi-platform index digest of a scanner image (`scanners.md` `## Image resolution`)                     |
| `image-verify`         | `docker image inspect --format '{{index .RepoDigests 0}}' <image>`                                                                                                                                                                                                                                                                 | Pulled digest; must equal the locked digest, else the scanner is `unavailable`                                                    |
| `image-build`          | `docker build -f <Dockerfile> -t cdk-vuln-scan/<slug>:<ts> <its dir>`                                                                                                                                                                                                                                                              | Build a repo Dockerfile for the image scanners (`scanners.md` `## Command templates`)                                             |
| `image-save`           | `RAW=$(cat "<run dir>/.raw-path") && docker save <ref> -o "$RAW/images/<slug>.tar"`                                                                                                                                                                                                                                                | Export an image once so no scanner needs the Docker socket                                                                        |
| `container-remove`     | `docker rm -f cdk-vs-<scanner>-<iteration>`                                                                                                                                                                                                                                                                                        | Remove this run's own scanner container after a timeout and when the skill stops; a missing container is not an error             |
| `image-remove`         | `docker rmi cdk-vuln-scan/<slug>:<ts>`                                                                                                                                                                                                                                                                                             | Remove an image tag this run built (step 9 and when the skill stops; a missing image is not an error)                             |
| `raw-cleanup`          | `rm -rf "$(cat "<repo root>/.vulnerability-reports/<ts>/.raw-path")"`                                                                                                                                                                                                                                                              | Remove the raw scanner dir saved at creation (`<ts>` = this run's dir name); runs after each scanner run and when the skill stops |
