# Commands

| Name               | Command                                                                           | Purpose                                                                                                                                                                                                           |
| ------------------ | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `check-agent`      | `node ${CLAUDE_SKILL_DIR}/scripts/check-agent.mjs <agent-file> [--scope <scope>]` | Mechanical rules (frontmatter, tools, scope-ignored fields, body structure) as JSON `{ok, errors, warnings}`; scope is `personal`, `project`, or `plugin`; exit 0 ok, 1 errors, 2 bad usage.                      |
| `validate-agents`  | `claude plugin validate <agents-dir>`                                             | Structural check of the agents directory (frontmatter parse; the directory must be named `agents`, else the path is read as a plugin root); needs Claude Code v2.1.233 or later. It does not flag unknown fields. |
| `claude-version`   | `claude --version`                                                                | Local version, compared with the gates in `docs-snapshot.md` `## Version gates`.                                                                                                                                  |
| `delegation-test`  | `claude --print "<task text or @<name> task text>"`                               | One-line print-mode call for the delegation test; run per `score.md` `## Delegation test`, never for a write-capable agent.                                                                                       |
| `debug-log-search` | `claude --debug --print "hi" 2>&1 \| grep -i "does not recognize or apply"`       | Searches the debug log for an ignored field message; no match → no ignored field found; a command that cannot run → `Not tested`.                                                                                 |
