# Commands

`<owner>`, `<repo>`, `<n>`, `<head>`, `<default>`, `<path>`, `<title>`, `<file>` are literal values from Input and earlier steps. Titles and bodies never go inline in a shell argument; the body goes to a scratch file (`--body-file`), the title is written to a scratch file and checked from stdin, and only a checked title (no quotes, metacharacters, or control chars) goes in `--title '<title>'`. MCP names are hints: discover the real ones at runtime with ToolSearch (`github pull request`); `—` = no MCP tool, run the Command.

| Name              | MCP tool (hint)                                                 | Command (`gh` fallback)                                                                                                | Purpose                                                                     |
| ----------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `auth`            | —                                                               | `gh auth status`                                                                                                       | Must succeed in the fallback, else tell the user to run `gh auth login`     |
| `origin`          | —                                                               | `git remote get-url origin`                                                                                            | Owner and repo of the working directory                                     |
| `default-branch`  | —                                                               | `git symbolic-ref --short refs/remotes/origin/HEAD`                                                                    | Base branch: output minus `origin/`; failure → ask                          |
| `head-branch`     | —                                                               | `git branch --show-current`                                                                                            | Head of the new PR; empty (detached) → stop                                 |
| `status`          | —                                                               | `git status --porcelain=v1 --branch`                                                                                   | Uncommitted changes, upstream, ahead count                                  |
| `pr-for-branch`   | `mcp__plugin_github_github__list_pull_requests` (`head`, open)  | `gh pr list --repo <owner>/<repo> --head '<head>' --state open --json number,url,title,body,isDraft`                   | An open PR for the head branch → switch to update                           |
| `pr-get`          | `mcp__plugin_github_github__pull_request_read` (`get`)          | `gh pr view <n> --repo <owner>/<repo> --json number,url,title,body,state,isDraft,baseRefName,headRefName`              | Current title, body, state; not open → stop                                 |
| `pr-diff`         | `mcp__plugin_github_github__pull_request_read` (`get_diff`)     | `gh pr diff <n> --repo <owner>/<repo>`                                                                                 | Diff of an existing PR                                                      |
| `pr-files`        | `mcp__plugin_github_github__pull_request_read` (`get_files`)    | `gh pr view <n> --repo <owner>/<repo> --json files`                                                                    | Changed files of an existing PR                                             |
| `commits`         | —                                                               | `git log --format=%s%n%b --no-merges origin/<default>..HEAD`                                                           | Commit messages of the new PR                                               |
| `diff`            | —                                                               | `git diff origin/<default>...HEAD`                                                                                     | Diff of the new PR                                                          |
| `template-lookup` | `mcp__plugin_github_github__get_file_contents` (default branch) | `gh api repos/<owner>/<repo>/contents/<path>?ref=<default>`                                                            | Probe the template paths in `body.md`; a directory listing lists candidates |
| `create`          | `mcp__plugin_github_github__create_pull_request`                | `gh pr create --repo <owner>/<repo> --base '<default>' --head '<head>' --title '<title>' --body-file <file> [--draft]` | Write: open the PR                                                          |
| `update`          | `mcp__plugin_github_github__update_pull_request`                | `gh pr edit <n> --repo <owner>/<repo> --title '<title>' --body-file <file>`                                            | Write: replace title and body                                               |
| `push`            | —                                                               | `git push -u origin '<head>'`                                                                                          | Write: one normal push, no flags                                            |
| `check-title`     | —                                                               | `node ${CLAUDE_SKILL_DIR}/scripts/check-title.mjs < <file>`                                                            | `{"ok":true}` exit 0, or `{"ok":false,"errors":[…]}` exit 1                 |
