# Commands

`<p>` is a protected name or glob; `<root>`, `<remote>`, `<branch>`, `<upstream-branch>`, `<owner>`, `<repo>`, and `<id>` are literal values, always in single quotes. In a `gh` or `glab` path, a `/` inside `<branch>` is written `%2F`.

| Name               | Command                                                                                               | Purpose                                                                         | MCP tool                                 |
| ------------------ | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ---------------------------------------- |
| `repo-root`        | `git -C '.' rev-parse --show-toplevel`                                                                | Repository root; failure = not a repository                                     | —                                        |
| `remotes`          | `git -C '<root>' remote -v`                                                                           | Remote names and URLs                                                           | —                                        |
| `remote-url`       | `git -C '<root>' remote get-url '<remote>'`                                                           | Remote URL; names the host                                                      | —                                        |
| `default-branch`   | `git -C '<root>' ls-remote --symref '<remote>' HEAD`                                                  | Default branch from the `ref: refs/heads/<name>` line                           | —                                        |
| `current-branch`   | `git -C '<root>' rev-parse --abbrev-ref HEAD`                                                         | Current branch; `HEAD` = detached                                               | —                                        |
| `worktrees`        | `git -C '<root>' worktree list --porcelain`                                                           | Branches checked out in any worktree                                            | —                                        |
| `fetch-all`        | `git -C '<root>' fetch --all --prune`                                                                 | Refresh remote-tracking refs and drop stale ones                                | —                                        |
| `list-local`       | `node "${CLAUDE_SKILL_DIR}/scripts/list-branches.mjs" '<root>' local '<remote>' --protected '<p>' …`  | JSON: `candidates`, `excluded`, `skipped`, `pages`; `<remote>` unused for local | —                                        |
| `list-remote`      | `node "${CLAUDE_SKILL_DIR}/scripts/list-branches.mjs" '<root>' remote '<remote>' --protected '<p>' …` | Same JSON for remote-tracking branches                                          | —                                        |
| `github-protected` | `gh api 'repos/<owner>/<repo>/branches?protected=true' --paginate`                                    | GitHub branches with classic protection                                         | GitHub MCP `list_branches` (`protected`) |
| `github-rules`     | `gh api 'repos/<owner>/<repo>/rules/branches/<branch>'`                                               | Ruleset rules on a branch; a non-empty list = protected                         | —                                        |
| `gitlab-protected` | `glab api 'projects/<id>/protected_branches'`                                                         | GitLab protected branches and wildcards; `<id>` = URL-encoded path              | GitLab MCP `list_branches` (protected)   |
| `ff-merge`         | `git -C '<root>' merge --ff-only '<upstream>'`                                                        | Fast-forward the current branch to its upstream                                 | —                                        |
| `ff-update`        | `git -C '<root>' fetch '<remote>' '<upstream-branch>:<branch>'`                                       | Fast-forward a non-current branch; refuses non-fast-forward                     | —                                        |
| `delete-local`     | `git -C '<root>' branch -d '<branch>'`                                                                | Delete a merged local branch                                                    | —                                        |
| `force-delete`     | `git -C '<root>' branch -D '<branch>'`                                                                | Delete an unmerged local branch, only after the force question                  | —                                        |
| `delete-remote`    | `git -C '<root>' push '<remote>' --delete '<branch>'`                                                 | Delete one remote branch                                                        | —                                        |
| `prune-remote`     | `git -C '<root>' fetch '<remote>' --prune`                                                            | Drop the deleted remote-tracking refs                                           | —                                        |
