# Commands

| Name              | Command                                                                                                                                | Purpose                                                                                                        |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `repo-root`       | `git rev-parse --show-toplevel`                                                                                                        | Repo root; fail falls back to cwd (preloaded in Context)                                                       |
| `actionlint`      | `actionlint <workflow files…>`                                                                                                         | Lint workflows and callees; run by the practices-review subagent                                               |
| `zizmor`          | `zizmor <.github/workflows> <.github/actions>`                                                                                         | Security audit of workflows and composite actions; run by the practices-review subagent                        |
| `act-probe`       | `command -v act` and `command -v docker`                                                                                               | Both must exist for the act check, else it reports `skipped`                                                   |
| `act-dry-run`     | `act -n`                                                                                                                               | Dry-run every workflow job without executing steps; run by the practices-review subagent                       |
| `gh-release`      | `gh api repos/<owner>/<repo>/releases/latest --jq .tag_name`                                                                           | Latest release tag when the GitHub MCP tools are unavailable; GET only; run by the version-resolution subagent |
| `ls-remote-tags`  | `git ls-remote --tags --refs https://github.com/<owner>/<repo>`                                                                        | List tags when a repo publishes no releases (404 from `gh-release`)                                            |
| `ls-remote-tag`   | `git ls-remote --tags https://github.com/<owner>/<repo> refs/tags/<tag>*`                                                              | Verify a tag exists and read its peeled commit SHA (`<tag>^{}`)                                                |
| `hub-tags`        | WebFetch `https://hub.docker.com/v2/namespaces/<namespace>/repositories/<repo>/tags?page_size=100&name=<major.minor>`                  | Docker Hub tag list, at most 10 pages; no shell command                                                        |
| `pick-tag`        | `node ${CLAUDE_SKILL_DIR}/scripts/resolve-versions.mjs action`, `image [--variant <name>]`, or `runner [--arch arm64]`, items on stdin | Highest stable tag or runner label by numeric semver; JSON `{ok, tag}` (`runner` adds `lts`)                   |
| `check-workflows` | `node ${CLAUDE_SKILL_DIR}/scripts/check-workflows.mjs <workflow and action files…>`                                                    | Mechanical `posix`, `pins`, `naming` checks; JSON `{ok, findings}`; run by the practices-review subagent       |
| `yaml-check`      | `actionlint <workflow files…>` parse result                                                                                            | YAML validity comes from actionlint's parse; actionlint not installed → report `yaml unverified`               |
