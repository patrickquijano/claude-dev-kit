# Commands

`<host>`, `<url>`, `<enc>`, `<iid>`, `<head>`, `<default>`, `<path>`, `<title>`, `<file>` are literal values from Input and earlier steps (see `gitlab-mapping.md`). Titles and bodies never go inline in a shell argument; the description goes to a scratch file (`--description-file`), the title is written to a scratch file and checked from stdin, and only a checked title (no quotes, metacharacters, or control chars) goes in `--title '<title>'`. MCP names are hints: discover the real ones at runtime with ToolSearch (`gitlab merge request`); `—` = no MCP tool, run the Command. Run `glab <command> --help` before the first use of each glab command.

| Name              | MCP tool (hint)                                                                                                       | Command (`glab` fallback)                                                                                                                                                                                          | Purpose                                                                                     |
| ----------------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| `auth`            | —                                                                                                                     | `glab auth status --hostname <host>`                                                                                                                                                                               | Must succeed in the fallback, else tell the user to run `glab auth login --hostname <host>` |
| `origin`          | —                                                                                                                     | `git remote get-url origin`                                                                                                                                                                                        | Host and project path of the working directory                                              |
| `default-branch`  | —                                                                                                                     | `git symbolic-ref --short refs/remotes/origin/HEAD`                                                                                                                                                                | Target branch: output minus `origin/`; failure → ask                                        |
| `head-branch`     | —                                                                                                                     | `git branch --show-current`                                                                                                                                                                                        | Source of the new MR; empty (detached) → stop                                               |
| `status`          | —                                                                                                                     | `git status --porcelain=v1 --branch`                                                                                                                                                                               | Uncommitted changes, upstream, ahead count                                                  |
| `mr-for-branch`   | — (`list_merge_requests` has no source-branch filter)                                                                 | `glab mr list -R <url> --source-branch '<head>' --output json`                                                                                                                                                     | Open MRs (the default) for the source branch → switch to update                             |
| `mr-get`          | `mcp__plugin_gitlab_gitlab__get_merge_request` (`project_id`, `merge_request_iid`)                                    | `glab mr view <iid> -R <url> --output json`                                                                                                                                                                        | Current title, description, state; not open → stop                                          |
| `mr-diff`         | `mcp__plugin_gitlab_gitlab__get_merge_request` (`include: [diffs]`, `detail: full_patch`)                             | `glab mr diff <iid> -R <url> --raw`                                                                                                                                                                                | Diff of an existing MR                                                                      |
| `mr-files`        | `mcp__plugin_gitlab_gitlab__get_merge_request` (`include: [diffs]`, `detail: stats`)                                  | `glab api --hostname <host> projects/<enc>/merge_requests/<iid>/diffs`                                                                                                                                             | Changed files of an existing MR                                                             |
| `commits`         | —                                                                                                                     | `git log --format=%s%n%b --no-merges origin/<default>..HEAD`                                                                                                                                                       | Commit messages of the new MR                                                               |
| `diff`            | —                                                                                                                     | `git diff origin/<default>...HEAD`                                                                                                                                                                                 | Diff of the new MR                                                                          |
| `template-lookup` | `mcp__plugin_gitlab_gitlab__list_repository_tree` + `mcp__plugin_gitlab_gitlab__get_repository_file` (default branch) | `glab api --hostname <host> 'projects/<enc>/repository/tree?path=.gitlab/merge_request_templates&ref=<default>'`, then `glab api --hostname <host> 'projects/<enc>/repository/files/<enc-file>/raw?ref=<default>'` | List the template directory, then read one file (`<enc-file>` = URL-encoded path)           |
| `create`          | `mcp__plugin_gitlab_gitlab__save_merge_request` (no IID)                                                              | `glab mr create -R <url> --source-branch '<head>' --target-branch '<default>' --title '<title>' --description-file <file> [--draft] --push=false --yes`                                                            | Write: open the MR; `--draft` always uses this command                                      |
| `update`          | `mcp__plugin_gitlab_gitlab__save_merge_request` (with the IID)                                                        | `glab mr update <iid> -R <url> --title '<title>' --description-file <file> --yes`                                                                                                                                  | Write: replace title and description                                                        |
| `push`            | —                                                                                                                     | `git push -u origin '<head>'`                                                                                                                                                                                      | Write: one normal push, no flags                                                            |
| `check-title`     | —                                                                                                                     | `node ${CLAUDE_SKILL_DIR}/scripts/check-title.mjs < <file>`                                                                                                                                                        | `{"ok":true}` exit 0, or `{"ok":false,"errors":[…]}` exit 1                                 |
