# Required skills

Skill dirs under `.claude/skills/<name>/` that this skill invokes. They come from `specify init` (core group).

- Core (third-party): `speckit-constitution`, `speckit-specify`, `speckit-clarify`, `speckit-plan`, `speckit-checklist`, `speckit-tasks`, `speckit-analyze`, `speckit-implement`, `speckit-converge`.
- Third-party `speckit-converge` is unverified: confirm it exists in the installed Spec Kit before relying on it; a missing dir stops the pre-flight like any other.
