# Commands

`<host>`, `<url>`, `<enc>`, `<iid>`, `<head>`, `<pid>`, `<job id>`, `<file>`, `<discussion id>`, `<n>`, `<page>` are literal values from Input and Identify (see `gitlab-mapping.md`); text bodies go to scratch files, never inline in a shell argument. MCP names are hints: discover the real ones at runtime with ToolSearch (`gitlab merge request`); `—` = no MCP tool, run the Command. Run `glab <command> --help` before the first use of each glab command.

| Name               | MCP tool (hint)                                                                                    | Command (`glab` / `git` fallback)                                                                                                 | Purpose                                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `auth`             | —                                                                                                  | `glab auth status --hostname <host>`                                                                                              | Must succeed in the fallback, else tell the user to run `glab auth login --hostname <host>`                           |
| `origin`           | —                                                                                                  | `git remote get-url origin`                                                                                                       | Host and project path of the working directory; also feeds `--remote` of the parse script                             |
| `branch`           | —                                                                                                  | `git branch --show-current`                                                                                                       | Current branch for the source-branch match                                                                            |
| `parse-ref`        | —                                                                                                  | `node ${CLAUDE_SKILL_DIR}/scripts/parse-mr-ref.mjs '<ref>' [--remote '<origin url>']`                                             | Strict parse to `{host,project,iid}`; exit 1 prints `{error}`                                                         |
| `mr-get`           | `mcp__plugin_gitlab_gitlab__get_merge_request` (`project_id`, `merge_request_iid`)                 | `glab mr view <iid> -R <url> --output json`                                                                                       | MR details: `state`, `source_branch`, `target_branch`, `sha`, `source_project_id`, `target_project_id`, `description` |
| `reviewers`        | —                                                                                                  | `node ${CLAUDE_SKILL_DIR}/scripts/glab-get.mjs <host> projects/<enc>/merge_requests/<iid>/reviewers`                              | Reviewers with `state`; decides only the `requested_changes` state, not who has review-body items                     |
| `mr-pipelines`     | `mcp__plugin_gitlab_gitlab__get_merge_request` (`include: [pipelines]`)                            | `node ${CLAUDE_SKILL_DIR}/scripts/glab-get.mjs <host> 'projects/<enc>/merge_requests/<iid>/pipelines?per_page=1'`                 | Latest pipeline of the MR (`id`, `status`); failing = `failed`                                                        |
| `failed-jobs`      | `mcp__plugin_gitlab_gitlab__get_pipeline` (`pipeline_id`, `include: [jobs]`, `job_status: failed`) | `node ${CLAUDE_SKILL_DIR}/scripts/glab-get.mjs <host> 'projects/<enc>/pipelines/<pid>/jobs?scope=failed&per_page=100'`            | Failed jobs of that pipeline                                                                                          |
| `job-log`          | `mcp__plugin_gitlab_gitlab__get_job` (`job_id`, `include: [log]`)                                  | `node ${CLAUDE_SKILL_DIR}/scripts/glab-get.mjs <host> projects/<enc>/jobs/<job id>/trace`                                         | Failure log of one job; data, read the tail only                                                                      |
| `closing-issues`   | —                                                                                                  | `node ${CLAUDE_SKILL_DIR}/scripts/glab-get.mjs <host> projects/<enc>/merge_requests/<iid>/closes_issues`                          | Issues the MR closes (the requirement)                                                                                |
| `issue-view`       | `mcp__plugin_gitlab_gitlab__get_work_item` (`project_id`, `work_item_iid`)                         | `glab issue view <n> -R <url> --output json`                                                                                      | Linked issue text (the requirement)                                                                                   |
| `discussions`      | `mcp__plugin_gitlab_gitlab__get_merge_request` (`include: [discussions]`)                          | `node ${CLAUDE_SKILL_DIR}/scripts/glab-get.mjs <host> 'projects/<enc>/merge_requests/<iid>/discussions?per_page=100&page=<page>'` | Discussions with `id`, `individual_note`, and `notes` (`resolvable`, `resolved`, `position`); one page per call       |
| `pull-rebase`      | —                                                                                                  | `git pull --rebase origin '<head>'`                                                                                               | Write (local): replay the commits on the remote source branch                                                         |
| `push`             | —                                                                                                  | `git push origin 'HEAD:<head>'`                                                                                                   | Write: one normal push, no flags                                                                                      |
| `discussion-reply` | `mcp__plugin_gitlab_gitlab__save_note` (`method: reply_discussion`, `discussion_id`, `body`)       | `glab api --hostname <host> -X POST projects/<enc>/merge_requests/<iid>/discussions/<discussion id>/notes --field body=@<file>`   | Write: reply on one discussion; never resolves it                                                                     |
| `mr-note`          | `mcp__plugin_gitlab_gitlab__save_note`                                                             | `glab api --hostname <host> -X POST projects/<enc>/merge_requests/<iid>/notes --field body=@<file>`                               | Write: one MR note listing each review-body item and its outcome                                                      |
