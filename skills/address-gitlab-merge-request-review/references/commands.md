# Commands

`<host>`, `<url>`, `<enc>`, `<iid>`, `<source_branch>`, `<pid>`, `<job id>`, `<file>`, `<discussion id>`, `<issue iid>`, `<author id>`, `<page>` are literal values from Input and Identify (see `gitlab-mapping.md`); text bodies go to scratch files, never inline in a shell argument. MCP names are hints (discovery per SKILL.md Rules); `—` = no MCP tool, run the Command. A `<path>` containing `'` or a control character is never substituted into `diff-path` or `log-paths`; list it under `Open:`. A `<source_branch>` containing `'` or a control character is never substituted into `pull-rebase` or `push`; stop at step 0 and report.
