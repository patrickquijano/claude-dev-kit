# Commands

`<host>`, `<url>`, `<enc>`, `<iid>`, `<sha>`, `<ref>`, `<enc-ref>`, `<merge sha>`, `<branch>` are literal values from Pre-flight, Resolve, and the pre-merge questions (see `gitlab-mapping.md`). MCP names are hints: discover the real ones at runtime with ToolSearch (`gitlab merge request`). MCP first; the Command is the fallback; `—` = no MCP tool, run the Command. Run `glab <command> --help` before the first use of each `glab` command. Every `glab api` read ends with `--method GET`.

| Name            | MCP tool (hint)                                                                                                      | Command (`glab` fallback)                                                                               | Purpose                                                                                                                                                                                                     |     |     |
| --------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
| `auth-status`   | —                                                                                                                    | `glab auth status --hostname <host>`                                                                    | Before the first `glab` row; failure → tell the user to `glab auth login --hostname <host>`                                                                                                                 |     |     |
| `origin`        | —                                                                                                                    | `git remote get-url origin`                                                                             | Host and project path, host must be GitLab                                                                                                                                                                  |     |     |
| `branch`        | —                                                                                                                    | `git branch --show-current`                                                                             | Current branch for the branch match                                                                                                                                                                         |     |     |
| `mr-for-branch` | — (`list_merge_requests` has no source-branch filter)                                                                | `glab mr list -R <url> --source-branch '<branch>' --output json`                                        | Open MR whose source is the current branch; empty = no match                                                                                                                                                |     |     |
| `mr-get`        | `mcp__plugin_gitlab_gitlab__get_merge_request` (`project_id`, `merge_request_iid`)                                   | `glab mr view <iid> -R <url> --output json`                                                             | Author, `state`, `draft`, `has_conflicts`, `detailed_merge_status`, `sha`, source and target branch and project ids, `force_remove_source_branch`, `head_pipeline`, `squash_commit_sha`, `merge_commit_sha` |     |     |
| `approvals`     | `mcp__plugin_gitlab_gitlab__get_merge_request` (`include: [approvals]`)                                              | `glab api --hostname <host> projects/<enc>/merge_requests/<iid>/approvals --method GET`                 | `approved`, `approved_by`, `approvals_left`                                                                                                                                                                 |     |     |
| `pipeline`      | `mcp__plugin_gitlab_gitlab__get_pipeline` (`id`, `pipeline_id` from `head_pipeline`)                                 | `glab mr view <iid> -R <url> --output json`                                                             | Head pipeline `status`; none = no pipeline                                                                                                                                                                  |     |     |
| `merge-methods` | —                                                                                                                    | `glab api --hostname <host> projects/<enc> --method GET`                                                | `merge_method` (`merge`, `rebase_merge`, `ff`), `squash_option`, `only_allow_merge_if_pipeline_succeeds`                                                                                                    |     |     |
| `dependents`    | — (`list_merge_requests` has no target-branch filter)                                                                | `glab mr list -R <url> --target-branch '<ref>' --output json`                                           | Open MRs that use the source branch as their target                                                                                                                                                         |     |     |
| `merge-mcp`     | `mcp__plugin_gitlab_gitlab__accept_merge_request` (`sha`, `squash`, `should_remove_source_branch`; never `strategy`) | —                                                                                                       | Write: the merge, pinned to the head SHA                                                                                                                                                                    |     |     |
| `merge-glab`    | —                                                                                                                    | `glab mr merge <iid> -R <url> --auto-merge=false [--squash] [--remove-source-branch] --sha <sha> --yes` | Write: merge fallback; `--squash` only for Squash, `--remove-source-branch` only for Delete                                                                                                                 |     |     |
| `merge-state`   | `mcp__plugin_gitlab_gitlab__get_merge_request` (`merge_request_iid`)                                                 | `glab mr view <iid> -R <url> --output json`                                                             | `state` and `merge_commit_sha`, `squash_commit_sha`                                                                                                                                                         |     |     |
| `merge-parents` | `mcp__plugin_gitlab_gitlab__get_commit` (parents of the SHA)                                                         | `glab api --hostname <host> projects/<enc>/repository/commits/<merge sha> --method GET`                 | `parent_ids` length of the merge commit                                                                                                                                                                     |     |     |
| `branch-exists` | `mcp__plugin_gitlab_gitlab__list_branches` (`search=^<ref>$`)                                                        | `glab api --hostname <host> projects/<enc>/repository/branches/<enc-ref> --method GET`                  | Source branch still present (200) or gone (404)                                                                                                                                                             |     |     |
