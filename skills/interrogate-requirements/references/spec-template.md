# Spec template

Read at step 9. Fill every section; write "None" for an empty one, never delete it.

## Contents

- Skeleton · Rules

## Skeleton

```markdown
# <Title>

## Goal

<One or two sentences.>

## Scope

- <In-scope item>

## Out of scope

- <Excluded item>

## Requirements

- R1: <One verifiable statement.>
- R2: <…>

## Decisions

| ID  | Choice   | Alternatives | Evidence      | Label                               |
| --- | -------- | ------------ | ------------- | ----------------------------------- |
| D1  | <chosen> | <others>     | <URL or note> | Verified / User-stated / Unverified |

## Assumptions

| ID  | Assumption | Status              |
| --- | ---------- | ------------------- |
| A1  | <text>     | confirmed / pending |

## Open questions

- <Question: why it stays open>
```

## Rules

- Requirement IDs `R1`… stay stable across updates; never renumber.
- Each requirement passes every quality criterion checked at step 2.
- A pending assumption also appears under Open questions.
