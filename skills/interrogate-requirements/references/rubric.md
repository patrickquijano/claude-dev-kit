## Quality criteria

A requirement passes only when every test below is true; each failure is a gap.

| #   | Criterion   | Pass test                                                       |
| --- | ----------- | --------------------------------------------------------------- |
| 1   | Unambiguous | One reading only; no "fast", "easy", "etc.", or undefined terms |
| 2   | Complete    | Actor, action, input, output, and error case are all stated     |
| 3   | Verifiable  | A concrete check says met or unmet                              |
| 4   | Consistent  | No other requirement or answer contradicts it                   |
| 5   | Atomic      | One statement, one requirement                                  |
| 6   | Necessary   | Traces to a stated goal                                         |
| 7   | Feasible    | Constraints (platform, budget, deadline) allow it               |
| 8   | Bounded     | Scope and out-of-scope edges are stated                         |
| 9   | Sourced     | Every fact carries an evidence label                            |

## Evidence labels

- Verified: backed by a cited URL, preferably official docs.
- User-stated: the user said it; not checked.
- Unverified: neither; includes every external claim when no search tool exists.
