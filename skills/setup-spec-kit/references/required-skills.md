# Required skills

Shared by `cdk:setup-spec-kit`, `cdk:assess-spec-kit-idea`, `cdk:fix-spec-kit-bug`, and `cdk:run-spec-kit`. The `cdk:` Spec Kit skills need every `.claude/skills/<name>/` dir below; their pre-flight checks the groups they use.

- Core (`specify init`, used by run-spec-kit): `speckit-constitution`, `speckit-specify`, `speckit-clarify`, `speckit-plan`, `speckit-checklist`, `speckit-tasks`, `speckit-analyze`, `speckit-implement`, `speckit-converge`.
- `assess` extension (used by assess-spec-kit-idea): `speckit-assess-intake`, `speckit-assess-research`, `speckit-assess-define`, `speckit-assess-shape`, `speckit-assess-decide`.
- `bug` extension (used by fix-spec-kit-bug): `speckit-bug-assess`, `speckit-bug-fix`, `speckit-bug-test`.
