# Required skills

Skill dirs under `.claude/skills/<name>/` that the cdk Spec Kit skills need.

- Core (`specify init`): `speckit-constitution`, `speckit-specify`, `speckit-clarify`, `speckit-plan`, `speckit-checklist`, `speckit-tasks`, `speckit-analyze`, `speckit-implement`, `speckit-converge`.
- `assess` extension: `speckit-assess-intake`, `speckit-assess-research`, `speckit-assess-define`, `speckit-assess-shape`, `speckit-assess-decide`.
- `bug` extension: `speckit-bug-assess`, `speckit-bug-fix`, `speckit-bug-test`.
