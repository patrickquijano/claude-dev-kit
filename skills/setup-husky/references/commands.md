# Commands

| Name               | Command                                                                                  | Purpose                                                                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `git-root`         | `git rev-parse --show-toplevel`                                                          | Fails outside a git repo (preloaded in Context)                                                                                                   |
| `node-version`     | `node --version`                                                                         | Fails when Node.js is missing (preloaded in Context)                                                                                              |
| `gpgsign`          | `git config --get commit.gpgsign`                                                        | Must be `true`                                                                                                                                    |
| `signingkey`       | `git config --get user.signingkey`                                                       | Must be set                                                                                                                                       |
| `allowed-signers`  | `git config --get gpg.ssh.allowedSignersFile`                                            | Needed for SSH signing                                                                                                                            |
| `gpg-format`       | `git config --get gpg.format`                                                            | `ssh` needs `allowed-signers`                                                                                                                     |
| `hooks-path`       | `git config --get core.hooksPath`                                                        | Current hooks directory                                                                                                                           |
| `pm-check`         | `command -v <pm>`                                                                        | Fails when the package manager is missing                                                                                                         |
| `add-dev`          | `<pm> add -D <pkg>@<v>`                                                                  | Add dev dependencies; add `-w` (pnpm) or `-W` (yarn 1) at a workspace root, per `package-manager.md`; `npm install -D`, `bun add -d` for npm, bun |
| `husky-init`       | `<exec> husky init`                                                                      | Initialize Husky                                                                                                                                  |
| `run-prepare`      | `<pm> run prepare`                                                                       | Install hooks, set `core.hooksPath`                                                                                                               |
| `chmod-exec`       | `chmod +x <path>`                                                                        | Make copied stubs executable                                                                                                                      |
| `merge-prepare`    | `node ${CLAUDE_SKILL_DIR}/scripts/merge-prepare.mjs --pkg <pkg> [--existing "<script>"]` | JSON `{prepare, action}`: merged `scripts.prepare`                                                                                                |
| `smoke-commit-msg` | `node <pkg>/.husky/commit-msg.mjs <file>`                                                | Check the commit-msg hook                                                                                                                         |
