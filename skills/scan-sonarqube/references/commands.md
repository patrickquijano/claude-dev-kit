# Commands

`<port>`, `<key>`, `<ts>`, `<n>`, `<envfile>`, and `<root>` are filled per run; `<envfile>` is `${TMPDIR:-/tmp}/cdk-sonar-<key>.env`. Commands that start with `set -a; . <envfile>; set +a;` read their secrets from `<envfile>`, so none is typed or printed.

| Name                 | Command                                                                                                                                                                                                                                                                                                                                                                                                                                            | Purpose                                                                                                                                                                                                |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `repo-root`          | `git rev-parse --show-toplevel`                                                                                                                                                                                                                                                                                                                                                                                                                    | Repository root (preloaded in Context)                                                                                                                                                                 |
| `detect`             | `node ${CLAUDE_SKILL_DIR}/scripts/sonar-setup.mjs detect --root <root>`                                                                                                                                                                                                                                                                                                                                                                            | JSON `{key, stack, scanner, scanCommand, jdk, exclusions, excluded, stop?, ask?}`: project key, stack, scan command, JDK, and exclusions per `flow.md` `## Stack`; one stderr line and exit 1 on error |
| `tags`               | `node ${CLAUDE_SKILL_DIR}/scripts/sonar-setup.mjs tags --stack <stack> [--jdk <n>]`                                                                                                                                                                                                                                                                                                                                                                | JSON `{server, scanner, scannerImage, source}`: exact image tags, looked up at most once per day (`source` = `cached` or `looked-up`); `image tag unresolved` error → stop                             |
| `docker-info`        | `docker info`                                                                                                                                                                                                                                                                                                                                                                                                                                      | Docker availability                                                                                                                                                                                    |
| `port-check`         | `lsof -nP -iTCP:<port> -sTCP:LISTEN`                                                                                                                                                                                                                                                                                                                                                                                                               | Exit 0 means the host port is taken                                                                                                                                                                    |
| `leftover-remove`    | `docker rm -fv cdk-sonar-<key>; docker network rm cdk-sonar-<key>; docker volume rm cdk-sonar-<key>-m2 cdk-sonar-<key>-gradle`                                                                                                                                                                                                                                                                                                                     | Remove objects left by a crashed run; missing objects are ignored                                                                                                                                      |
| `env-create`         | `umask 077; printf 'SONAR_PORT=%s\nSONAR_ADMIN_PASSWORD=%s\nSONAR_TOKEN=\n' <port> "$(openssl rand -hex 16)Aa1!" > <envfile>`                                                                                                                                                                                                                                                                                                                      | Create the mode 600 secrets file outside the repo; never print it                                                                                                                                      |
| `network-create`     | `docker network create cdk-sonar-<key>`                                                                                                                                                                                                                                                                                                                                                                                                            | Network shared by the server and the scanner                                                                                                                                                           |
| `server-run`         | `docker run -d --name cdk-sonar-<key> --network cdk-sonar-<key> --network-alias sonarqube -p <port>:9000 -e SONAR_ES_BOOTSTRAP_CHECKS_DISABLE=true sonarqube:<server-tag>`                                                                                                                                                                                                                                                                         | Start the server; its anonymous volumes go with `docker rm -fv`                                                                                                                                        |
| `server-status`      | `curl -fsS http://localhost:<port>/api/system/status`                                                                                                                                                                                                                                                                                                                                                                                              | Ready when the JSON has `"status":"UP"`; poll every 5 s, at most 120 tries                                                                                                                             |
| `server-logs`        | `docker logs --tail 50 cdk-sonar-<key>`                                                                                                                                                                                                                                                                                                                                                                                                            | Last server log lines; the evidence when the server is not ready                                                                                                                                       |
| `admin-password-set` | `set -a; . <envfile>; set +a; curl -fsS -u admin:admin -X POST "http://localhost:$SONAR_PORT/api/users/change_password" -d login=admin -d previousPassword=admin --data-urlencode "password=$SONAR_ADMIN_PASSWORD"`                                                                                                                                                                                                                                | Replace the default admin password on a fresh server; HTTP 204 = done                                                                                                                                  |
| `token-generate`     | `set -a; . <envfile>; set +a; curl -fsS -u "admin:$SONAR_ADMIN_PASSWORD" -X POST "http://localhost:$SONAR_PORT/api/user_tokens/generate" -d name=cdk-sonar-<ts> -d type=GLOBAL_ANALYSIS_TOKEN \| node -e 'const t=JSON.parse(require("fs").readFileSync(0,"utf8")).token;const f=process.argv[1];const s=require("fs").readFileSync(f,"utf8").replace(/^SONAR_TOKEN=.*$/m,"SONAR_TOKEN="+t);require("fs").writeFileSync(f,s)' <envfile>`           | Create an analysis token and store it in `<envfile>` without printing it                                                                                                                               |
| `scan-cli`           | `set -a; . <envfile>; set +a; docker run --rm --network cdk-sonar-<key> -e SONAR_HOST_URL=http://sonarqube:9000 -e SONAR_TOKEN -v "<root>:/src:ro" --entrypoint sh <scanner-image>:<scanner-tag> -c 'cp -a /src/. /tmp/work && cd /tmp/work && sonar-scanner -Dsonar.projectKey=<key> -Dsonar.qualitygate.wait=true -Dsonar.exclusions=<exclusions>'`                                                                                              | `cli` stack: analyze a copy of the read-only repo and wait for the server to process it; `<exclusions>` per `flow.md` `## Exclusions`                                                                  |
| `scan-maven`         | `set -a; . <envfile>; set +a; docker run --rm --network cdk-sonar-<key> -e SONAR_HOST_URL=http://sonarqube:9000 -e SONAR_TOKEN -v "<root>:/src:ro" -v cdk-sonar-<key>-m2:/root/.m2 --entrypoint sh <scanner-image>:<scanner-tag> -c 'cp -a /src/. /tmp/work && cd /tmp/work && mvn -B clean verify org.sonarsource.scanner.maven:sonar-maven-plugin:sonar -Dsonar.projectKey=<key> -Dsonar.qualitygate.wait=true -Dsonar.exclusions=<exclusions>'` | `maven` stack: build, analyze, and wait for the server; needs no pom change                                                                                                                            |
| `scan-gradle`        | `set -a; . <envfile>; set +a; docker run --rm --network cdk-sonar-<key> -e SONAR_HOST_URL=http://sonarqube:9000 -e SONAR_TOKEN -v "<root>:/src:ro" -v cdk-sonar-<key>-gradle:/root/.gradle --entrypoint sh <scanner-image>:<scanner-tag> -c 'cp -a /src/. /tmp/work && cd /tmp/work && gradle sonar -Dsonar.projectKey=<key> -Dsonar.qualitygate.wait=true -Dsonar.exclusions=<exclusions>'`                                                       | `gradle` stack: analyze through the `org.sonarqube` plugin the build already applies                                                                                                                   |
| `issues-search`      | `set -a; . <envfile>; set +a; curl -fsS -u "$SONAR_TOKEN:" "http://localhost:$SONAR_PORT/api/issues/search?componentKeys=<key>&issueStatuses=OPEN,CONFIRMED&ps=500&p=<n>" \| node -e 'const d=JSON.parse(require("fs").readFileSync(0,"utf8"));for(const i of d.issues)console.log([i.key,i.severity,i.rule,i.component.replace(/^[^:]*:/,"")+":"+(i.line\|\|0),i.message].join("\t"));console.error("total="+d.total)'`                           | Open issues as `key severity rule path:line message` lines, `total=` on stderr; next page while `p * 500 < total`                                                                                      |
| `rule-show`          | `set -a; . <envfile>; set +a; curl -fsS -u "$SONAR_TOKEN:" "http://localhost:$SONAR_PORT/api/rules/show?key=<rule>" \| node -e 'const r=JSON.parse(require("fs").readFileSync(0,"utf8")).rule;const s=(r.descriptionSections\|\|[]).map(x=>x.content).join(" ");console.log(r.name+" ["+r.severity+"]\n"+(s\|\|r.htmlDesc\|\|"").replace(/<[^>]+>/g," ").replace(/\s+/g," ").trim().slice(0,1500))'`                                               | One rule's name, severity, and description text (tags stripped, 1500 chars); empty text → use the issue message only                                                                                   |
| `teardown`           | `docker rm -fv cdk-sonar-<key>; docker network rm cdk-sonar-<key>; docker volume rm cdk-sonar-<key>-m2 cdk-sonar-<key>-gradle`                                                                                                                                                                                                                                                                                                                     | Remove the server and its anonymous volumes, the network, and the cache volume; missing objects are ignored; images stay                                                                               |
| `env-remove`         | `rm -f <envfile>`                                                                                                                                                                                                                                                                                                                                                                                                                                  | Delete the secrets file                                                                                                                                                                                |
