# Commands

`<port>`, `<key>`, `<name>`, `<ts>`, `<n>`, `<envfile>`, and `<root>` are filled per run; `<name>` is `name` from `detect` (the Docker object name), and `<envfile>` is the path `env-create` printed. Commands that start with `set -a; . <envfile>; set +a;` read their secrets from `<envfile>`, so none is typed or printed.

| Name                 | Command                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Purpose                                                                                                                                                                                                                                                                                                                           |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `repo-root`          | `git rev-parse --show-toplevel`                                                                                                                                                                                                                                                                                                                                                                                                                                            | Repository root (preloaded in Context)                                                                                                                                                                                                                                                                                            |
| `detect`             | `node ${CLAUDE_SKILL_DIR}/scripts/sonar-setup.mjs detect --root <root> [--stack <maven\|gradle>]`                                                                                                                                                                                                                                                                                                                                                                          | JSON `{key, name, stack, scanner, scanCommand, jdk, exclusions, excluded, dropped, stop?, ask?}`: project key, Docker object name, stack, scan command, JDK, and exclusions per `flow.md` `## Stack`; `dropped` lists exclusion patterns with unsafe characters; `--stack` resolves an `ask`; one stderr line and exit 1 on error |
| `tags`               | `node ${CLAUDE_SKILL_DIR}/scripts/sonar-setup.mjs tags --stack <stack> [--jdk <n>]`                                                                                                                                                                                                                                                                                                                                                                                        | JSON `{server, scanner, scannerImage, source}`: exact image tags, looked up at most once per day (`source` = `cached` or `looked-up`); `image tag unresolved` error → stop                                                                                                                                                        |
| `docker-info`        | `docker info`                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Docker availability                                                                                                                                                                                                                                                                                                               |
| `port-check`         | `lsof -nP -iTCP:<port> -sTCP:LISTEN`                                                                                                                                                                                                                                                                                                                                                                                                                                       | Exit 0 means the host port is taken                                                                                                                                                                                                                                                                                               |
| `leftover-remove`    | `docker rm -fv <name>; docker network rm <name>; docker volume rm <name>-m2 <name>-gradle`                                                                                                                                                                                                                                                                                                                                                                                 | Remove objects left by a crashed run; missing objects are ignored                                                                                                                                                                                                                                                                 |
| `env-create`         | `umask 077; f=$(mktemp "${TMPDIR:-/tmp}/cdk-sonar.XXXXXX") && printf 'SONAR_PORT=%s\nSONAR_ADMIN_PASSWORD=%s\nSONAR_TOKEN=\n' <port> "$(openssl rand -hex 16)Aa1!" > "$f" && echo "$f"`                                                                                                                                                                                                                                                                                    | Create the mode 600 secrets file outside the repo and print only its path (`<envfile>`); never print its content                                                                                                                                                                                                                  |
| `network-create`     | `docker network create <name>`                                                                                                                                                                                                                                                                                                                                                                                                                                             | Network shared by the server and the scanner                                                                                                                                                                                                                                                                                      |
| `server-run`         | `docker run -d --name <name> --network <name> --network-alias sonarqube -p 127.0.0.1:<port>:9000 -e SONAR_ES_BOOTSTRAP_CHECKS_DISABLE=true sonarqube:<server-tag>`                                                                                                                                                                                                                                                                                                         | Start the server, bound to loopback; its anonymous volumes go with `docker rm -fv`                                                                                                                                                                                                                                                |
| `server-status`      | `curl -fsS http://localhost:<port>/api/system/status`                                                                                                                                                                                                                                                                                                                                                                                                                      | Ready when the JSON has `"status":"UP"`; poll every 5 s, at most 120 tries                                                                                                                                                                                                                                                        |
| `server-logs`        | `docker logs --tail 50 <name>`                                                                                                                                                                                                                                                                                                                                                                                                                                             | Last server log lines; the evidence when the server is not ready                                                                                                                                                                                                                                                                  |
| `admin-password-set` | `set -a; . <envfile>; set +a; printf 'user = "admin:admin"\ndata-urlencode = "password=%s"\n' "$SONAR_ADMIN_PASSWORD" \| curl -fsS -K - -X POST "http://localhost:$SONAR_PORT/api/users/change_password" -d login=admin -d previousPassword=admin`                                                                                                                                                                                                                         | Replace the default admin password on a fresh server, with the credentials in a curl config on stdin; HTTP 204 = done                                                                                                                                                                                                             |
| `token-generate`     | `set -a; . <envfile>; set +a; printf 'user = "admin:%s"\n' "$SONAR_ADMIN_PASSWORD" \| curl -fsS -K - -X POST "http://localhost:$SONAR_PORT/api/user_tokens/generate" -d name=cdk-sonar-<ts> -d type=GLOBAL_ANALYSIS_TOKEN \| node -e 'const t=JSON.parse(require("fs").readFileSync(0,"utf8")).token;const f=process.argv[1];const s=require("fs").readFileSync(f,"utf8").replace(/^SONAR_TOKEN=.*$/m,"SONAR_TOKEN="+t);require("fs").writeFileSync(f,s)' <envfile>`       | Create an analysis token and store it in `<envfile>` without printing it                                                                                                                                                                                                                                                          |
| `scan-cli`           | `set -a; . <envfile>; set +a; docker run --rm --network <name> -e SONAR_HOST_URL=http://sonarqube:9000 -e SONAR_TOKEN -e "SONAR_EXCLUSIONS=<exclusions>" -v "<root>:/src:ro" --entrypoint sh <scanner-image>:<scanner-tag> -c 'cp -a /src/. /tmp/work && cd /tmp/work && sonar-scanner -Dsonar.projectKey=<key> -Dsonar.qualitygate.wait=true -Dsonar.exclusions="$SONAR_EXCLUSIONS"'`                                                                                     | `cli` stack: analyze a copy of the read-only repo and wait for the server to process it; `<exclusions>` per `flow.md` `## Exclusions`                                                                                                                                                                                             |
| `scan-maven`         | `set -a; . <envfile>; set +a; docker run --rm --network <name> -e SONAR_HOST_URL=http://sonarqube:9000 -e SONAR_TOKEN -e "SONAR_EXCLUSIONS=<exclusions>" -v "<root>:/src:ro" -v <name>-m2:/root/.m2 --entrypoint sh <scanner-image>:<scanner-tag> -c 'cp -a /src/. /tmp/work && cd /tmp/work && mvn -B clean verify org.sonarsource.scanner.maven:sonar-maven-plugin:sonar -Dsonar.projectKey=<key> -Dsonar.qualitygate.wait=true -Dsonar.exclusions="$SONAR_EXCLUSIONS"'` | `maven` stack: build, analyze, and wait for the server; needs no pom change                                                                                                                                                                                                                                                       |
| `scan-gradle`        | `set -a; . <envfile>; set +a; docker run --rm --network <name> -e SONAR_HOST_URL=http://sonarqube:9000 -e SONAR_TOKEN -e "SONAR_EXCLUSIONS=<exclusions>" -v "<root>:/src:ro" -v <name>-gradle:/root/.gradle --entrypoint sh <scanner-image>:<scanner-tag> -c 'cp -a /src/. /tmp/work && cd /tmp/work && gradle sonar -Dsonar.projectKey=<key> -Dsonar.qualitygate.wait=true -Dsonar.exclusions="$SONAR_EXCLUSIONS"'`                                                       | `gradle` stack: analyze through the `org.sonarqube` plugin the build already applies                                                                                                                                                                                                                                              |
| `issues-search`      | `set -a; . <envfile>; set +a; printf 'user = "%s:"\n' "$SONAR_TOKEN" \| curl -fsS -K - "http://localhost:$SONAR_PORT/api/issues/search?componentKeys=<key>&issueStatuses=OPEN,CONFIRMED&ps=500&p=<n>" \| node -e 'const d=JSON.parse(require("fs").readFileSync(0,"utf8"));for(const i of d.issues)console.log([i.key,i.severity,i.rule,i.component.replace(/^[^:]*:/,"")+":"+(i.line\|\|0),i.message].join("\t"));console.error("total="+d.total)'`                       | Open issues as `key severity rule path:line message` lines, `total=` on stderr; next page while `p * 500 < total`                                                                                                                                                                                                                 |
| `rule-show`          | `set -a; . <envfile>; set +a; printf 'user = "%s:"\n' "$SONAR_TOKEN" \| curl -fsS -K - "http://localhost:$SONAR_PORT/api/rules/show?key=<rule>" \| node -e 'const r=JSON.parse(require("fs").readFileSync(0,"utf8")).rule;const s=(r.descriptionSections\|\|[]).map(x=>x.content).join(" ");console.log(r.name+" ["+r.severity+"]\n"+(s\|\|r.htmlDesc\|\|"").replace(/<[^>]+>/g," ").replace(/\s+/g," ").trim().slice(0,1500))'`                                           | One rule's name, severity, and description text (tags stripped, 1500 chars); empty text → use the issue message only                                                                                                                                                                                                              |
| `teardown`           | `docker rm -fv <name>; docker network rm <name>; docker volume rm <name>-m2 <name>-gradle`                                                                                                                                                                                                                                                                                                                                                                                 | Remove the server and its anonymous volumes, the network, and the cache volume; missing objects are ignored; images stay                                                                                                                                                                                                          |
| `env-remove`         | `rm -f <envfile>`                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Delete the secrets file                                                                                                                                                                                                                                                                                                           |
