# Commands

| Name              | Command                                                                                                                                            | Purpose                                    |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `root`            | `git rev-parse --show-toplevel`                                                                                                                    | Repository root (preloaded in Context)     |
| `remotes`         | `git remote`                                                                                                                                       | Lists remotes                              |
| `gh-version`      | `gh --version`                                                                                                                                     | gh installed                               |
| `gh-auth`         | `gh auth status`                                                                                                                                   | gh authenticated                           |
| `repo-view`       | `gh repo view --json nameWithOwner,url,viewerPermission`                                                                                           | Repo and permission                        |
| `origin-url`      | `git remote get-url origin`                                                                                                                        | Origin URL (preloaded in Context)          |
| `status`          | `git status --porcelain=v1`                                                                                                                        | Empty = clean tree                         |
| `current-branch`  | `git rev-parse --abbrev-ref HEAD`                                                                                                                  | Current branch name (preloaded in Context) |
| `fetch`           | `git fetch --prune origin`                                                                                                                         | Refresh remote refs                        |
| `fetch-tags`      | `git fetch origin --tags`                                                                                                                          | Fetch tags, no force                       |
| `ff-main`         | `git merge --ff-only origin/main`                                                                                                                  | Fast-forward main                          |
| `head-sha`        | `git rev-parse HEAD`                                                                                                                               | Local tip                                  |
| `origin-main-sha` | `git rev-parse origin/main`                                                                                                                        | Remote tip                                 |
| `scratch`         | `mktemp -d`                                                                                                                                        | Scratch directory                          |
| `plan`            | `node ${CLAUDE_SKILL_DIR}/../../hooks/scripts/changelog-release.mjs plan --repo-url <Repo url> --notes-out <scratch>/notes.md [--prefix <prefix>]` | Plan version, tag, notes                   |
| `release-view`    | `gh release view <tag> --json url,isDraft,isPrerelease,targetCommitish`                                                                            | Release exists check                       |
| `release-list`    | `gh release list --limit 1000 --json tagName,isDraft,url`                                                                                          | Finds draft releases                       |
| `local-tag`       | `git rev-parse -q --verify "refs/tags/<tag>^{commit}"`                                                                                             | Local tag commit                           |
| `remote-tag`      | `git ls-remote origin "refs/tags/<tag>" "refs/tags/<tag>^{}"`                                                                                      | Remote tag commit                          |
| `create-tag`      | `git tag -a <tag> -m "Release <version>" <commit>`                                                                                                 | Annotated tag                              |
| `push-tag`        | `git push origin "refs/tags/<tag>"`                                                                                                                | Plain tag push                             |
| `create-release`  | `gh release create <tag> --verify-tag --title <tag> --notes-file <scratch>/notes.md`                                                               | Publish release                            |
| `verify-release`  | `gh release view <tag> --json url,tagName,isDraft,isPrerelease,targetCommitish`                                                                    | Verify published release                   |
