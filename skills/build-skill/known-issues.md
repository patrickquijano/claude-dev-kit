# Known issues

Shared by every `cdk:` skill. `<skill>` is the slug the linking skill names.

- Before fixing an issue, check auto memory (`MEMORY.md` index) for a matching issue of `<skill>`; reuse its fix.
- Recurring or workflow-blocking issue fixed (incl. subagent `Known issue:` lines) → save memory file `<skill>-<short-slug>.md` (type `feedback`, body `<symptom> → <fix>`) plus its `MEMORY.md` pointer.
- Never record a known issue in a `SKILL.md` or agent file.
- Auto memory unavailable → print `<symptom> → <fix>` for the user.
