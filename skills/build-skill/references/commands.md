# Commands

| Name              | Command                                                                                                                             | Purpose                                                                                                                                                                                                                                                      |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `validate-plugin` | `claude plugin validate --strict .`                                                                                                 | Structural check of a plugin root (frontmatter parse, layout); run from the plugin root.                                                                                                                                                                     |
| `check-skill`     | `node ${CLAUDE_SKILL_DIR}/scripts/check-skill.mjs <skill-dir> --kind <task\|reference\|background-only> [--allow <plugin-path>]...` | Mechanical rules (F1, F3, F6, F8, B1, B4, B6, B9, Q1, L2, L3) as JSON `{ok, errors, warnings}`; exit 0 ok, 1 errors, 2 bad usage. Each repeatable `--allow` accepts a plugin-relative path (a trailing `/` allows a directory) that L3 would otherwise flag. |
