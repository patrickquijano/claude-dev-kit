# Commands

`<owner>`, `<repo>`, `<n>`, `<path>`, `<title>`, `<file>`, `<label>`, `<query>` are literal values from Input and earlier steps. Titles and bodies never go inline in a shell argument; the body goes to a scratch file (`--body-file`) and only a title with no quotes, metacharacters, or control chars goes in `--title '<title>'`. MCP names are hints: discover the real ones at runtime with ToolSearch (`github issue`, `github label`, `github file contents`) and call them first; use the `gh` command only for an operation whose MCP tool is unavailable; `—` = no such route.

| Name               | MCP tool (hint)                                                 | Command (`gh` fallback)                                                                                             | Purpose                                                                 |
| ------------------ | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `auth`             | —                                                               | `gh auth status`                                                                                                    | Fallback only: must succeed, else tell the user to run `gh auth login`  |
| `origin`           | —                                                               | `git remote get-url origin`                                                                                         | Owner and repo from a bare number                                       |
| `issue-get`        | `mcp__plugin_github_github__issue_read` (`get`)                 | `gh issue view <n> --repo <owner>/<repo> --json number,url,title,body,labels,state,issueType`                       | Current title, body, labels, type, state                                |
| `issue-search`     | `mcp__plugin_github_github__search_issues`                      | `gh issue list --repo <owner>/<repo> --state open --search '<query>' --json number,url,title`                       | Open duplicates before a create                                         |
| `template-lookup`  | `mcp__plugin_github_github__get_file_contents` (default branch) | `gh api repos/<owner>/<repo>/contents/<path>`                                                                       | Probe the template paths in `template.md`; a directory lists candidates |
| `label-list`       | the MCP label-list tool found by ToolSearch                     | `gh label list --repo <owner>/<repo> --limit 200 --json name,description`                                           | The repo's own label set                                                |
| `label-get`        | `mcp__plugin_github_github__get_label`                          | `gh label list --repo <owner>/<repo> --search '<label>' --json name,description`                                    | Confirm one label exists                                                |
| `list-issue-types` | `mcp__plugin_github_github__list_issue_types`                   | —                                                                                                                   | Valid issue types; no route → skip types                                |
| `label-create`     | the MCP label write tool found by ToolSearch                    | `gh label create '<label>' --repo <owner>/<repo>`                                                                   | Write, asked: create a missing label                                    |
| `create`           | `mcp__plugin_github_github__issue_write` (`create`)             | `gh issue create --repo <owner>/<repo> --title '<title>' --body-file <file> [--label '<label>']...`                 | Write: open the issue                                                   |
| `update`           | `mcp__plugin_github_github__issue_write` (`update`)             | `gh issue edit <n> --repo <owner>/<repo> --title '<title>' --body-file <file> [--add-label ... --remove-label ...]` | Write: replace title and body, change labels                            |

Step 1 records, per operation, whether it runs on MCP or `gh`. `Tool:` reports `mcp`, `gh`, or `mcp+gh:<ops on gh>`.
