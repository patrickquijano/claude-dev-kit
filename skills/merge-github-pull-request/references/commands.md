# Commands

`<owner>`, `<repo>`, `<n>`, `<sha>`, `<base>`, `<ref>`, `<merge sha>`, `<method>` are literal values from Pre-flight, Resolve, and the pre-merge questions. `<method>` is `squash`, `merge`, or `rebase`. MCP first; the Command is the fallback.

| Name              | Command                                                                                                                                                | Purpose                                                               | MCP tool                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| `auth-status`     | `gh auth status`                                                                                                                                       | Before the first `gh` row; failure → tell the user to `gh auth login` | —                                                                                       |
| `origin`          | `git remote get-url origin`                                                                                                                            | Host check, must be `github.com`                                      | —                                                                                       |
| `branch`          | `git branch --show-current`                                                                                                                            | Current branch for the branch match                                   | —                                                                                       |
| `self`            | `gh api user --jq .login`                                                                                                                              | Login of the user                                                     | `mcp__plugin_github_github__get_me` (`login`)                                           |
| `pr-for-branch`   | `gh pr view <branch> --repo <owner>/<repo> --json number,url,state`                                                                                    | Open PR whose head is the current branch; error = no match            | `mcp__plugin_github_github__list_pull_requests` (`head=<owner>:<branch>`, `state=open`) |
| `pr-get`          | `gh pr view <n> --repo <owner>/<repo> --json number,url,state,isDraft,author,baseRefName,headRefName,headRefOid,isCrossRepository,headRepositoryOwner` | Author, state, draft, head SHA, base, head ref                        | `mcp__plugin_github_github__pull_request_read` (`get`)                                  |
| `reviews`         | `gh pr view <n> --repo <owner>/<repo> --json reviews`                                                                                                  | Review states                                                         | `mcp__plugin_github_github__pull_request_read` (`get_reviews`)                          |
| `checks`          | `gh pr checks <n> --repo <owner>/<repo> --json name,state,bucket`                                                                                      | All check results                                                     | `mcp__plugin_github_github__pull_request_read` (`get_check_runs`)                       |
| `pr-gaps`         | `gh pr view <n> --repo <owner>/<repo> --json mergeable,mergeStateStatus,reviewDecision,headRefOid`                                                     | Fields MCP `get` lacks                                                | —                                                                                       |
| `checks-required` | `gh pr checks <n> --repo <owner>/<repo> --required --json name,state,bucket`                                                                           | Required-checks-only filter (MCP gap)                                 | —                                                                                       |
| `permission`      | `gh repo view <owner>/<repo> --json viewerPermission`                                                                                                  | The user's permission, `ADMIN` needed for bypass                      | `mcp__plugin_github_github__list_repository_collaborators` (`role_name`)                |
| `merge-methods`   | `gh repo view <owner>/<repo> --json squashMergeAllowed,mergeCommitAllowed,rebaseMergeAllowed`                                                          | Allowed merge methods                                                 | —                                                                                       |
| `rules`           | `gh api repos/<owner>/<repo>/rules/branches/<base>`                                                                                                    | Ruleset blockers; empty or 404 = none                                 | —                                                                                       |
| `dependents`      | `—`                                                                                                                                                    | Open PRs that use the head ref as their base                          | `mcp__plugin_github_github__list_pull_requests` (`base=<ref>`, `state=open`)            |
| `merge-mcp`       | `—`                                                                                                                                                    | Write: standard merge with Keep branch                                | `mcp__plugin_github_github__merge_pull_request` (`merge_method`, `expectedHeadSha`)     |
| `merge-gh`        | `gh pr merge <n> --repo <owner>/<repo> --<method> [--delete-branch] --match-head-commit <sha>`                                                         | Write: standard merge fallback, or with Delete branch (MCP gap)       | —                                                                                       |
| `merge-admin`     | `gh pr merge <n> --repo <owner>/<repo> --<method> --admin [--delete-branch] --match-head-commit <sha>`                                                 | Write: bypass merge (MCP gap)                                         | —                                                                                       |
| `merge-commit`    | `gh pr view <n> --repo <owner>/<repo> --json state,mergeCommit`                                                                                        | Merged state and merge commit SHA                                     | `mcp__plugin_github_github__pull_request_read` (`get`)                                  |
| `merge-parents`   | `gh api repos/<owner>/<repo>/commits/<merge sha> --jq '.parents \| length'`                                                                            | Parent count of the merge commit                                      | `mcp__plugin_github_github__get_commit` (parents of the SHA)                            |
| `branch-exists`   | `gh api repos/<owner>/<repo>/branches/<ref>`                                                                                                           | Head ref still present (200) or gone (404)                            | —                                                                                       |
