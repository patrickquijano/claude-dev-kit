# Commands

`<owner>`, `<repo>`, `<n>`, `<sha>`, `<path>`, `<file>` are literal values from Pre-flight and Resolve; text bodies go to scratch files, never inline in a shell argument; `<path>` is validated and single-quoted per the Rules in `SKILL.md`.

| Name             | Command                                                                                                                                                                                                                                                                                                                                                                                                     | Purpose                                                                                                          | MCP tool                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `auth-status`    | `gh auth status`                                                                                                                                                                                                                                                                                                                                                                                            | Authenticated `gh` session                                                                                       | —                                                                         |
| `origin`         | `git remote get-url origin`                                                                                                                                                                                                                                                                                                                                                                                 | Host check, must be `github.com` (preloaded in Context)                                                          | —                                                                         |
| `branch`         | `git branch --show-current`                                                                                                                                                                                                                                                                                                                                                                                 | Current branch for the branch match (preloaded in Context)                                                       | —                                                                         |
| `repo-view`      | `gh repo view --json nameWithOwner,url`                                                                                                                                                                                                                                                                                                                                                                     | Owner and repo of the working directory                                                                          | —                                                                         |
| `self`           | `gh api user --jq .login`                                                                                                                                                                                                                                                                                                                                                                                   | Login of the reviewer                                                                                            | `mcp__plugin_github_github__get_me`                                       |
| `pr-resolve-url` | `gh pr view <url> --json number,url,state,isDraft,headRefOid`                                                                                                                                                                                                                                                                                                                                               | Resolve a PR URL or number to its repo, state, and head                                                          | `mcp__plugin_github_github__pull_request_read`                            |
| `pr-for-branch`  | `gh pr view <branch> --repo <owner>/<repo> --json number,url,state,isDraft,headRefOid,headRepositoryOwner`                                                                                                                                                                                                                                                                                                  | Open PR whose head is the current branch; error = no match                                                       | `mcp__plugin_github_github__pull_request_read`                            |
| `pr-view`        | `gh pr view <n> --repo <owner>/<repo> --json number,url,title,body,author,baseRefName,baseRefOid,headRefName,headRefOid,state,isDraft,isCrossRepository,closingIssuesReferences,files,commits,reviews,statusCheckRollup`                                                                                                                                                                                    | Full PR details, head SHA, and checks                                                                            | `mcp__plugin_github_github__pull_request_read`                            |
| `pr-diff`        | `gh pr diff <n> --repo <owner>/<repo>`                                                                                                                                                                                                                                                                                                                                                                      | Unified diff to scratch                                                                                          | `mcp__plugin_github_github__pull_request_read` (`get_diff`)               |
| `file-at-sha`    | `gh api 'repos/<owner>/<repo>/contents/<path>?ref=<sha>' -H 'Accept: application/vnd.github.raw'`                                                                                                                                                                                                                                                                                                           | One file at the head SHA to scratch                                                                              | `mcp__plugin_github_github__get_file_contents`                            |
| `issue-view`     | `gh issue view <number> --repo <owner>/<repo> --json title,body,state`                                                                                                                                                                                                                                                                                                                                      | Linked issue text                                                                                                | `mcp__plugin_github_github__issue_read`                                   |
| `review-threads` | `gh api graphql -f query='query($o:String!,$r:String!,$n:Int!){repository(owner:$o,name:$r){pullRequest(number:$n){reviewThreads(first:100){nodes{id isResolved isOutdated viewerCanResolve path line comments(first:5){nodes{author{login} body url createdAt}} lastComment: comments(last:1){nodes{databaseId author{login} body createdAt originalCommit{oid}}}}}}}}' -f o=<owner> -f r=<repo> -F n=<n>` | Read query: open and resolved threads with their comments                                                        | `mcp__plugin_github_github__pull_request_read` (`get_review_comments`)    |
| `head-sha`       | `gh pr view <n> --repo <owner>/<repo> --json headRefOid,state,isDraft`                                                                                                                                                                                                                                                                                                                                      | Re-fetch the head SHA and state before posting                                                                   | `mcp__plugin_github_github__pull_request_read`                            |
| `thread-reply`   | `gh api graphql -f query='mutation($t:ID!,$b:String!){addPullRequestReviewThreadReply(input:{pullRequestReviewThreadId:$t,body:$b}){comment{url}}}' -f t=<thread id> -F b=@<file>`                                                                                                                                                                                                                          | Write: reply on one thread                                                                                       | `mcp__plugin_github_github__add_reply_to_pull_request_comment`            |
| `thread-resolve` | `gh api graphql -f query='mutation($t:ID!){resolveReviewThread(input:{threadId:$t}){thread{isResolved}}}' -f t=<thread id>`                                                                                                                                                                                                                                                                                 | Write: resolve one thread                                                                                        | —                                                                         |
| `review-create`  | `gh api repos/<owner>/<repo>/pulls/<n>/reviews -X POST --input <file>`                                                                                                                                                                                                                                                                                                                                      | Write: pending review; the file holds `commit_id`, `body`, no `event` (inline comments go through `add-comment`) | `mcp__plugin_github_github__pull_request_review_write` (`create`)         |
| `add-comment`    | `gh api graphql -f query='mutation($r:ID!,$p:String!,$l:Int!,$b:String!){addPullRequestReviewThread(input:{pullRequestReviewId:$r,path:$p,line:$l,side:RIGHT,body:$b}){thread{id}}}' -f r=<review node id> -f p='<path>' -F l=<line> -F b=@<file>`                                                                                                                                                          | Write: one inline comment on the pending review                                                                  | `mcp__plugin_github_github__add_comment_to_pending_review`                |
| `review-submit`  | `gh api repos/<owner>/<repo>/pulls/<n>/reviews/<review id>/events -X POST -f event=<EVENT> -F body=@<file>`                                                                                                                                                                                                                                                                                                 | Write: submit the pending review as `REQUEST_CHANGES`, `COMMENT`, or `APPROVE`                                   | `mcp__plugin_github_github__pull_request_review_write` (`submit_pending`) |
