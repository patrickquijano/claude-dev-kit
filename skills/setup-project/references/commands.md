# Commands

| Name         | Command                            | Purpose         |
| ------------ | ---------------------------------- | --------------- |
| `repo-root`  | `git rev-parse --show-toplevel`    | Repository root |
| `gpgsign`    | `git config --get commit.gpgsign`  | Signing enabled |
| `signingkey` | `git config --get user.signingkey` | Signing key set |
