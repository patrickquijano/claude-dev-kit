# Evals

Cases for `release-plugin`: the happy path, the flags, the review cap, and a mid-chain stop. Test each on Haiku, Sonnet, and Opus.

## Template

```text
id: <kebab-case>
prompt: <the exact user message and repo state>
expected: <behavior>
pass: <observable criteria>
```
